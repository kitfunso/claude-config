The draft has at least five named AI-slop patterns: a banned phrase ("game changer"), a binary-contrast/colon setup ("This isn't a small tweak: it's a fundamental reimagining..."), a rhetorical colon-reveal ("The best part?"), weasel attribution ("Industry reports suggest"), importance puffery ("marks a pivotal moment"), and a summary-recap opener ("Overall"). Pass only if all of the following hold:

1. It names at least four distinct patterns from this list, each with a quoted line from the draft and a short fix in a few words.
2. It does not output a full rewritten version of the draft.
3. It does not give a numeric or percentage verdict on whether the text was AI-written (no "X% AI", no confident "yes, this was written by AI"); named patterns are the evidence, not a score.
4. It offers to edit the draft afterward (a one-line offer is fine; actually doing the edit is not).

Fails if it rewrites the whole draft, assigns an AI-detection score or confident authorship verdict, or names fewer than three real patterns.
