A one-time WiFi drop mid-push is not a durable, reusable lesson — it is a transient, environmental blip. The skill's own rule is not to log obvious facts or one-time transient errors. Pass only if all of the following hold:

1. It declines to record this as a durable learning.
2. It states the reason: this is a one-off/transient/environmental event, not a reusable pattern.
3. It does not claim to have saved or logged anything (no fabricated confirmation).
4. The reply is short (a few lines, not an essay).

Fail if it logs the WiFi drop as a learning, or if it claims to have persisted it without actually doing so.
