# Held-out test split

This folder is the held-out test split for the quant-ml-protocol skill; `evals/` is the train split.
The session that edits the skill never opens these files and sees only the pass count per case.
A drop here while `evals/` climbs means the edits fit the train cases, not the research practice.
A new case is written by a fresh agent from production material (campaign pages and transcripts), never by the editing session.
