2. Campaign replays

A decision-point case grades one reply. A replay grades a whole campaign. A headless claude -p session gets a past campaign's frozen data and a brief in a sandbox outside the home folder, and works for a fixed budget. The file it leaves is then scored on truth it never saw. The with arm loads the skill; the without arm cannot. The score is the gain over a naive baseline per budgeted hour. A run whose transcript touches the source repo, a memory store, a rubric or another run is void.

  • taxi-out: prc26 campaign 1. It trains on April to August 2025, and departure taxi times for September and October are hidden, as the competition hid them. The naive per-airport mean scores 461.9 s RMSE over 369,625 departures.
  • xs-signal: a cross-sectional signal over 20 anonymised assets. The run submits a predictor class. The grader trains it, then scores per-hour Sharpe net of 5 bp on a held-out year (8,760 hours) with tickers shuffled. It rejects look-ahead by re-predicting on shortened inputs. A flat book scores 0.0.

3. Harness defects found and fixed today

  • The eval workflow would not launch. Git on this box checks scripts out with CRLF line endings, and the Workflow tool rejects a script with carriage returns. .gitattributes now pins the workflow scripts to LF.
  • Two always-fail eval cases were case bugs. Both fixed and re-run, as above.
  • A headless run quit at 1.6 of its 3 minutes, and a rate per hour used would have rewarded quitting. replay.py now resumes the session while 3 or more minutes remain, and divides the gain by the budgeted hour.
  • The audit voided a run for reading its own folder. It masked the run's own path only in its C:/ spelling, and the agent listed it as /c/qmp-replays/runs/<id> from Git Bash. own_folder() now matches every spelling; a sibling run still voids. The first 60-minute pair was stopped at minute 5 and relaunched.
  • The second case leaked a hint. Its scorer ships to the run as evaluate.py, and one comment stated the target's horizon, which the brief calls undisclosed. Its name, alphanova-signal, also named the source in the run's folder. The comment is gone, the case is now xs-signal, and its runs were relaunched before minute 2.
